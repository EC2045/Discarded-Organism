# Discarded Organism — 東暦版バックルーム（仮）

> 制作中の世界観資料。バックルームは通称で、正式名称は未定。

神が世界創造時に試作・廃棄したデータの断片が残る「現実の外側」の領域。生命体、建築物、文明、物理法則、記憶などの未採用データが存在する。多くの領域は無人で、一部に廃棄生命体がいる。

**接続方式は不明**。和温陣国の首都外部は現実そのものが不安定で、廃棄領域と接触する可能性が考えられるが未確認。神の管理状況も「神のみぞ知る」。
